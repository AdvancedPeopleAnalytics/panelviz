# Available looks

`"economist"` (default), `"ft"`, `"clean"`, `"dark"` and `"mono"`
(print-friendly greys). Choose one for a session with
[`use_panel_style()`](https://advancedpeopleanalytics.github.io/panelviz/reference/use_panel_style.md),
or per chart with `style =`.

## Usage

``` r
panel_styles()
```

## Value

`panel_styles()` returns the names.
